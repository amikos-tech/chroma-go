# Quick Task 260730-p46: Remove Legacy docker/docker Module Summary

Removed `github.com/docker/docker` from the chroma-go dependency graph entirely by upgrading Testcontainers to v0.43.0, inlining the `modules/chroma` wrapper, and migrating test-only Docker API type imports to `github.com/moby/moby/api`.

## What Was Done

### Task 1 — Go floor raised to 1.25.0 (`b391cee`)

Bumped the `go` directive from `1.24.11` to `1.25.0` in the root `go.mod` and all 11 `examples/v2/*/go.mod` files. No `toolchain` directive was added anywhere — all 14 CI `setup-go` invocations read `go-version-file: 'go.mod'`, so the floor propagates automatically.

This bump was forced, not discretionary: the Testcontainers upgrade pulls `golang.org/x/crypto v0.51.0`, which itself declares `go 1.25.0`.

### Task 2 — docker/docker removed (`fd44958`)

Source edits landed **before** module resolution, so `go mod tidy` could not re-add `docker/docker` to satisfy stale imports.

- Swapped 8 import lines across 4 tagged test files from `github.com/docker/docker/api/types/{container,mount}` to `github.com/moby/moby/api/types/{container,mount}`. Package names and all call sites (`container.HostConfig`, `mount.Mount`, `mount.TypeBind`) were unchanged.
- Deleted the `tcchroma` import and inlined the single live call site in `TestClientHTTPIntegrationWithSSL`, replacing `tcchroma.Run` with `testcontainers.Run` plus `WithExposedPorts("8000/tcp")` and `WithWaitStrategy(wait.ForListeningPort("8000/tcp"))` as leading customizers, keeping the caller's `WithEnv`/`CustomizeRequest` last so the existing `WaitingFor` override still wins. `RESTEndpoint(...)` became `PortEndpoint(ctx, "8000/tcp", "http")`.
- Removed the dead commented-out `tcchroma` block (former lines 773-786), the last `tcchroma` reference in the repo.
- Upgraded `testcontainers-go` and `modules/ollama` to v0.43.0 and dropped the `modules/chroma` and `docker/docker` requires.

`github.com/moby/moby/api v1.54.2` and `github.com/moby/moby/client v0.4.0` entered the graph as the upstream successors, exactly as the plan predicted.

### Task 3 — Example modules synced, docs updated (`20f41c9`)

Tidied the 9 buildable example modules to pick up the upgraded `golang.org/x/{crypto,sys,text}` versions, and updated `docs/go-examples/README.md` from `Go 1.21+` to `Go 1.25+`.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 - Blocking] Testcontainers v0.43.0 changed the wait-strategy port type**

- **Found during:** Task 2 verification (`go vet -tags=crosslang`)
- **Issue:** v0.43.0 changed `wait.ForListeningPort(port string)` and `(*HTTPStrategy).WithPort(port string)` from accepting `nat.Port` to accepting `string`. The plan's verified-facts block listed the symbols as unchanged but did not catch this signature change. Three files failed to compile: `pkg/api/v2/client_local_crosslang_integration_test.go`, `pkg/embeddings/cross_lang_integration_test.go` (tag `crosslang`), and `pkg/embeddings/persistence_integration_test.go` (tag `ef`).
- **Fix:** Replaced `nat.Port("8000/tcp")` with the plain string `"8000/tcp"` at all 4 call sites and removed the resulting unused `nat` imports.
- **Note on plan intent:** The plan said to leave `github.com/docker/go-connections/nat` untouched. That instruction was about not removing the *module* as part of the docker/docker purge — and it is honored: `go-connections v0.6.0` remains in `go.mod` (now `// indirect`) and in `go.sum`. Only the now-invalid call-site usage changed, which the new API made mandatory.
- **Commit:** `fd44958`

**2. [Rule 3 - Blocking] Example modules needed re-tidying**

- **Found during:** Task 3
- **Issue:** All 9 buildable examples failed with `go: updates to go.mod needed`. Each carries a `replace github.com/amikos-tech/chroma-go => ../../../`, so the root module's upgraded transitive deps propagated into them.
- **Fix:** Ran `go mod tidy` in each; only `golang.org/x/crypto`, `golang.org/x/sys`, and `golang.org/x/text` version lines changed.
- **Commit:** `20f41c9`

**3. [Housekeeping] Removed build artifacts**

Verification builds emitted binaries (`main`, `auth`) into 9 example directories. These were deleted rather than committed or gitignored; adding 9 `.gitignore` entries would have been scope creep.
