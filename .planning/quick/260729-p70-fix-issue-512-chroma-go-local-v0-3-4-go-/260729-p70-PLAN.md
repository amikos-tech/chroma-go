<objective>
Resolve issue #512: `github.com/amikos-tech/chroma-go-local v0.3.4` fails `go.sum` verification
on any cold Go module cache, breaking `Smoke (windows-latest)` and `Smoke (macos-latest)`.

The `v0.3.4` tag upstream was re-cut from `5cdd82e4` onto `ad3a5aa` AFTER `sum.golang.org`
notarized it. Because `sum.golang.org` is append-only, the version number `v0.3.4` is
permanently bound to the old tree hash and can never be corrected. The only legitimate
resolution is a NEW version number carrying correctly notarized content.

Purpose: unbreak CI and, more importantly, unbreak every new user running
`go get github.com/amikos-tech/chroma-go` against a cold module cache.

Output:
1. Annotated tag `v0.3.5` in `amikos-tech/chroma-go-local` at commit `ad3a5aa` (zero content delta).
2. Root `go.mod`/`go.sum` bumped to v0.3.5.
3. 9 example modules re-tidied to pick up v0.3.5 through their replaced parent.
4. Cold-cache proof that the CI failure no longer reproduces.
</objective>
